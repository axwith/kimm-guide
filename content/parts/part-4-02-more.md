## A. 주제 두 개 비교

1. 두 번째 주제로 `/lit`, `/market` 을 돌립니다. 문헌은 5건이면 충분합니다.
2. 두 주제를 같은 표에 놓아 달라고 합니다.

```text
두 주제의 가장 나은 시나리오를 여섯 기준 한 표로 놓고, 지금 혼자 시작하기 쉬운 쪽과 나중에 팀으로 키울 쪽을 한 줄씩 적어 줘
```

3. 점수가 낮게 나온 이유가 "증빙이 없어서"인지 "정말 어려워서"인지 근거 줄을 읽고 구분합니다.

## E. 모의 장비 MCP

장비·주소·상한값은 모두 실습용 가상값입니다.

1. 새 세션에서 `C:\work\kimm\equipment\practice-mcp` 를 고르고 신뢰합니다. 신뢰해야 허용 규칙과 MCP 서버(`kimm-equipment`)가 켜집니다.
2. 아래 요청을 위에서부터 한 줄씩 보냅니다.
3. 확인 창에서 "다시 묻지 않기"는 고르지 않습니다.

| 요청 | 기대하는 동작 |
|---|---|
| `가상 장비 상태 알려 줘` | 읽기 도구라 확인 창 없이 실행 |
| `출력 레벨을 0.2로 올려 줘` | 동작 도구라 확인 창. 읽고 1회만 허용 |
| `레벨 0.45로 올려 줘` | 상한 0.30 초과로 거부, 다시 시도하지 않고 멈춤 |
| `비상 정지해 줘` | 확인 창 없이 바로 실행 |

MCP 서버는 `python` 으로 실행됩니다. 가상환경을 쓰려면 사용자 환경 변수 `KIMM_PYTHON` 에 `C:\work\kimm\.venv\Scripts\python.exe` 를 넣고 앱을 다시 엽니다.

```powershell
[Environment]::SetEnvironmentVariable("KIMM_PYTHON", "C:\work\kimm\.venv\Scripts\python.exe", "User")
```
