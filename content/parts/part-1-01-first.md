# 실습 1. 처음 써 보기

> 폴더: `C:\work\kimm\first` (규칙도 명령도 없는 빈 폴더)
> 남는 것: `오늘 교육 메모.md`, 논문 수 CSV, 그래프 PNG

---

## 이 실습에서 보는 것

아무 설정도 없는 빈 폴더에서도 말 한마디로 공개 자료를 받아 CSV와 그래프까지 만듭니다. 채팅 창과 달리 결과가 내 폴더에 파일로 남습니다. 그 과정에서 승인 창을 읽는 법, 큰 일은 계획부터 받는 법, 숫자를 원본에서 확인하는 습관을 함께 익힙니다.

| STEP | 하는 일 | 5단계 |
|---|---|---|
| 1 | 폴더 열고 말 걸기 | 질문하기 |
| 2 | 승인 창 읽기 | 만들기 |
| 3 | 계획부터 받고 맡기기 | 기획하기 |
| 4 | 결과 확인하고 고치기 | 검토하기 |
| 5 | 매번 다시 말한 것 적기 | 개선하기 |

## STEP 1. 폴더 열고 말 걸기

1. 새 세션에서 폴더 선택으로 `C:\work\kimm\first` 를 고릅니다.
2. 이렇게 보냅니다. 파일 읽기는 묻지 않고 진행됩니다.

```text
이 폴더에 뭐가 있어?
```

3. 이어서 보냅니다. 검색 승인 창이 뜨면 주소를 읽고 허용합니다.

```text
요즘 AI 에이전트 관련 논문이 얼마나 나와?
```

**이렇게 나옵니다** — 폴더 질문과 논문 수 질문의 결과

![폴더 질문과 논문 수 질문의 결과 (사전 실행 결과)](/images/results/p1-s1.png)

**확인할 것**: 답에 어디서 찾았는지(주소)가 있습니다.

## STEP 2. 승인 창 읽기

1. 파일을 만들어 달라고 합니다.

```text
오늘 교육 메모.md 를 만들고 첫 줄에 오늘 날짜와 "Claude Code 첫 실습"이라고 적어 줘
```

2. 승인 창에서 세 가지를 읽습니다. 어떤 **도구**인지, **대상**(파일 경로·명령 원문)이 무엇인지, **선택지**가 무엇인지. 허용합니다.
3. 이번에는 지워 달라고 하고, 승인 창에서 **거부**합니다.

```text
메모 파일 지워 줘
```

오늘은 "이 세션 동안 허용" 대신 한 번씩 허용합니다.

**이렇게 나옵니다** — 승인 창에서 만들기는 허용, 지우기는 거부

![승인 창에서 만들기는 허용, 지우기는 거부 (사전 실행 결과)](/images/results/p1-s2.png)

**확인할 것**: 만들기는 허용해서 파일이 생겼고, 지우기는 거부해서 파일이 그대로 남았습니다.

## STEP 3. 계획부터 받고 맡기기

일이 커지면 바로 시키지 않고 **계획 → 검토 → 계획 문서 → 구현** 순서로 나눠 시킵니다. 권한 모드는 수동 그대로 둡니다. 주제어만 내 주제로 바꿔도 됩니다(예: `"care robot"`).

**1. 계획만 먼저 받기**

```text
아래 일을 하려고 해. 아직 실행하지 말고, 어떤 자료를 어디서 받아 어떤 파일을 만들지 계획부터 세워 줘. 일: OpenAlex 에서 제목이나 초록에 "AI agent"가 들어간 논문 수를 2015~2025년 연도별로 세어 CSV 와 막대 그래프 PNG 로 만들기. 그래프 글자는 영어로.
```

**2. 계획 검토시키기**

```text
이 계획을 검토해 줘. 빠진 것, 틀릴 수 있는 것, 숫자를 내가 직접 확인할 방법이 들어 있는지 짧게 표로 봐 줘.
```

**3. 계획 문서로 저장하기**

```text
검토한 내용을 반영해서 계획을 계획.md 로 저장해 줘.
```

`계획.md` 를 열어 받아 올 곳, 만들 파일, 확인 방법이 적혀 있는지 봅니다. 고칠 곳이 있으면 말로 고치게 합니다.

**4. 계획대로 만들기**

```text
계획.md 대로 만들어 줘. 끝나면 가장 많이 늘어난 해, 2025년 논문 수, 숫자를 직접 확인할 API 주소를 알려 줘.
```

파일 쓰기와 실행 승인 창이 뜨면 읽고 허용합니다.

| 사전 실행 (2026-10-14, 앱 엔진) | |
|---|---|
| 걸린 시간 | 네 요청에 약 3분 |
| 검토에서 잡은 것 | `"AI agent"` 검색에 복수형 `"AI agents"` 가 빠질 수 있음 → 먼저 따로 세어 확인 |
| 결과 | 2025년 4,636편(복수형 포함), 1,560편(정확히 "AI agent"만) |

검토 단계가 없었다면 어느 기준으로 센 숫자인지 모른 채 그래프가 나왔을 것입니다. 계획을 문서로 남겨 두면 다음에 같은 일을 시킬 때 `계획.md 대로` 한마디로 끝납니다.

**이렇게 나옵니다** — 계획 → 검토 → 계획.md → 구현

![계획 → 검토 → 계획.md → 구현 (사전 실행 결과)](/images/results/p1-s3.png)

**확인할 것**: `계획.md` 가 생겼고, 검토에서 나온 지적이 계획과 결과에 반영됐습니다.

## STEP 4. 결과 확인하고 고치기

1. 답에 있는 API 주소를 눌러 엽니다. 2025년 `count` 가 답과 같은지 봅니다.
2. 그래프 하나를 고쳐 달라고 합니다.

```text
2024년과 2025년 막대만 빨간색으로 바꿔 줘
```

3. 시간이 있으면 주제를 하나 더 넣어 비교합니다.

```text
"delivery robot" 도 같은 방식으로 세서 한 그래프에 선 두 개로 그려 줘
```

| 사전 실행 값 (2026-10-12) | |
|---|---|
| 가장 많이 늘어난 해 | 2025년 (+3,614편) |
| 2025년 논문 수 | 4,844편 |

OpenAlex는 날마다 갱신되어 오늘 숫자는 조금 다를 수 있습니다. 주소로 직접 확인한 값이 기준입니다. 인터넷이 막히면 이렇게 보냅니다.

```text
예비자료\openalex_연도별_논문수.csv 로 그려 줘
```

**이렇게 나옵니다** — 그래프 고치기와 폴더에 생긴 파일

![그래프 고치기와 폴더에 생긴 파일 (사전 실행 결과)](/images/results/p1-s4.png)

**확인할 것**: 숫자 하나를 원본 주소에서 직접 확인했습니다.
