# 실습 2. 내 워크스페이스 만들기

> 폴더: `C:\work\kimm\research-planner`
> 남는 것: 연구 프로필, 작업 스타일·용어집, 자료 요약 카드, 보유 역량표, `CLAUDE.md` 의 "나에 대해"

---

## 이 실습에서 보는 것

인터뷰와 내 공개 자료로 이 폴더가 "나"를 알게 만듭니다. 새 세션을 열어도 설명 없이 나를 알고 시작하는 것을 확인합니다. 실적은 **증빙(자료)이 있을 때만 "보유"** 로 적힙니다. 이 구분이 실습 3의 공고 적합도 판정에 그대로 쓰입니다.

## 두 가지 방식

| | 1. 강사 따라 하기 | 2. 내 자료로 |
|---|---|---|
| 대상 | 처음 쓰는 분 | 써 본 분 |
| 자료 | 강사 공개 자료 5개(폴더에 들어 있음) | 내 공개 자료 10개 이내: 논문, 학회 발표, 공개 보고서 |
| 인터뷰 | 준비된 답(`인터뷰답.md`) | 내 정보로 답 |
| 덤 | 강사 화면과 같은 결과 | 내가 쓰던 방식과 비교해 가져다 쓸 것 고르기 |

넣지 않는 것: 기관 내부 문서, 미공개 데이터·시험 결과, 장비 정보, 과제명, 개인정보. HWP는 PDF로 저장해서 넣습니다.

관심 주제가 없으면 AI 에이전트, 돌봄 로봇, 폐배터리 재활용, 수면 웨어러블, 배달 로봇 중 하나를 고릅니다.

---

## 시작

1. 새 세션에서 `C:\work\kimm\research-planner` 를 고릅니다.
2. "이 폴더를 신뢰하시겠습니까" 창에서 신뢰합니다. 신뢰한 폴더에서만 플러그인과 규칙이 켜집니다.
3. 입력창의 **+ → Plugins** 에서 플러그인 여섯 개(insane-research, insane-search, kkirikkiri, skillers-suda, docs-guide, show-me-the-prd)가 켜졌는지 봅니다. 안 켜져도 실습 2는 진행됩니다.
4. 이렇게 보냅니다.

```text
/lab2
```

실습 전체 흐름이 먼저 나오고, 방식(강사 따라 하기 / 내 자료로)을 선택 창에서 고릅니다.

---

## STEP 1. 나를 알려 주기 — 질문하기

```text
/onboarding
```

선택 질문은 선택 창에서 고르고, 나머지는 한두 줄로 답합니다. 강사 따라 하기는 준비된 답이 자동으로 쓰입니다.

| # | 질문 | 강사 답(예) |
|---|---|---|
| 1 | 소속 유형 | 그 밖 · 1인 기업 |
| 2 | 분야와 하는 일 | AI 에이전트 도구 개발·교육 |
| 3 | 역할 | 연구 책임·기획 |
| 4 | 가장 오래 걸리는 반복 업무 | 사례 조사·출처 확인, 공고 훑기 |
| 5 | 주로 쓰는 문서 | 보고서, 과제 계획서, 발표 |
| 6 | 답변 방식 | 결론 먼저, 표·숫자 위주 |
| 7 | 하지 말 것 | 비유·슬로건, 확인 안 한 수치 |
| 8 | 관심 주제 | AI 에이전트로 연구자의 문서 업무 줄이기 |

**확인할 것**: 8번 관심 주제가 실습 3의 주제가 됩니다.

---

## STEP 2. 넣을 자료 고르기 — 기획하기

- 강사 따라 하기: 강사 자료 5개가 이미 `00-inbox` 에 들어 있습니다. 탐색기로 열어 봅니다.
- 내 자료로: 탐색기에서 `00-inbox` 에 최근 공개 자료 10개 이내를 복사합니다.

다 넣었으면 선택 창에서 "다 넣었어요"를 고릅니다.

**확인할 것**: 넣은 파일이 모두 이미 공개한 자료입니다.

---

## STEP 3. 흡수 — 만들기

흡수(`/kb ingest`)는 자동으로 돕니다. 파일 쓰기 승인 창을 읽고 허용합니다. 끝나면:

1. `70-kb\sources` 의 카드 하나를 열어 요지·방법·수치·원본 위치를 봅니다.
2. `70-kb\assets\보유역량.md` 에서 "보유"와 "부분"을 봅니다.

| 사전 실행 결과(강사 자료 5개) | 상태 | 근거 |
|---|---|---|
| 공개 플러그인 모음 | 보유 | 공개 GitHub |
| R&D 과제 파이프라인 | 보유 | 공개 GitHub |
| 공개 세미나 2건 | 부분 | 발표 자료만 |
| 기구 설계·시험 10년 | 부분 | 자기 소개 진술만 |

자료 10개(약 60KB) 흡수는 사전 실행에서 2분 남짓 걸렸습니다.

**확인할 것**: "보유"는 증빙이 있는 것뿐입니다.

---

## STEP 4. "이렇게 이해했어요" 대조 — 검토하기

하는 일, 문서 스타일, 용어, 증빙 있는 실적이 나옵니다. 내 실제 문서와 한 줄씩 비교합니다. 틀린 곳이 있으면 선택 창에서 "고칠 곳이 있어요"를 고르고:

```text
○○는 틀렸어, △△야. 고쳐서 다시 보여 줘
```

자료 두 개 이상에서 보인 것만 "습관"으로 적고, 하나에서만 보인 것은 "관찰"로 둡니다.

**확인할 것**: 스타일 항목 하나 이상을 내 문서와 직접 대조했습니다.

---

## STEP 5. 반영 확인과 비교 — 개선하기

1. `CLAUDE.md` 맨 아래 `## 나에 대해` 를 엽니다.
2. 새 세션을 열고 보냅니다.

```text
나에 대해 아는 것을 말해 줘
```

3. 써 본 분은 원래 쓰던 방식과 비교합니다.

```text
내가 원래 쓰던 방식은 ○○야. 이 워크스페이스와 비교해서 여기만 있는 것, 나만 있는 것, 가져다 쓸 것을 표로 정리해 줘
```

**확인할 것**: 새 세션의 답에 오늘 정한 내용이 나오고, 가져다 쓸 것 하나를 메모했습니다.

끝나면 `완료` 라고 보냅니다. 회고 한 줄을 묻고 `90-log\실습\lab2.md` 에 기록합니다.
